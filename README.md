# readpicture 使用指南：如何获取 API Key

readpicture 是一个让 AI 助手描述图片的小工具，调用的是智谱 AI 的视觉模型。第一次使用前，需要先申请一个智谱平台的 API Key。

## 第一步：注册智谱 AI 开放平台账号

1. 用浏览器打开[智谱 AI 开放平台](https://open.bigmodel.cn)
2. 点击右上角“注册”，用手机号注册并登录。
3. 按页面提示完成实名认证（新账号的免费额度通常需要实名后才能使用）。

## 第二步：创建 API Key

1. 登录后进入控制台。
2. 在左侧菜单找到“API 密钥”（API Keys）页面。
3. 点击“创建 API Key”（或“新建密钥”）。
4. 创建成功后，页面会显示一串密钥，形如：

   `xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx.xxxxxxxxxxxx`

5. 点击“复制”，把密钥保存好。


### 完成以上操作后，将获取到的key发给你的Agent,让它完成配置。

---

## 注意事项

- API Key 相当于密码，请勿发给无关人员，也不要上传到公开的代码仓库。
- 模型 `glm-4v-flash` 目前提供免费额度，超出后是否收费以及具体价格以智谱平台官网说明为准。
- 如果调用时报 `401` 错误，通常是 Key 填错或已失效，请回到第二步重新创建。
